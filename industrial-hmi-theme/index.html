用于昆仑通态触摸屏

这是一套可编辑的 HTML 主题与素材工具。可直接离线打开 HTML，在电脑上制作画面素材，再导入触摸屏工程。

建议的使用流程

  1. 选择触摸屏实际分辨率，先导出一张完整背景。
  2. 选择控件，设置宽高。对于动态数值和工程内文字，关闭「导出时包含文字」。
  3. 导出 PNG，导入工程图片资源；将按钮、指示灯的两张状态图片关联到相应状态。
  4. 在工程内叠加文字、数值和触摸动作，绑定实际变量，再检查触摸区域与状态切换。
素材使用方式
背景 / 信息框作为底图，文字和变量可在工程内叠加。
按钮 / 开关normal / active 或 off / on 两态成对导出。
指示灯红、黄、绿、蓝、灰各含亮 / 灭两态。
数值 / 液位 / 进度PNG 为当前数值的静态图；持续变化的数值使用工程内变量和绘图控件。

优先以 1× 实际像素导出；文字和触摸区域按目标屏幕检查。PNG 透明通道的显示效果取决于具体屏型号与工程版本，可先导入一个按钮验证；必要时关闭透明背景后导出。
