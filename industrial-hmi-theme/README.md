# 深蓝工业触控主题

面向昆仑通态（MCGS）触摸屏画面素材制作的独立 HTML 工具。参考深蓝渐变、青蓝高光、切角边框的工业科技风格，所有图形通过内嵌 SVG 绘制。

## 打开

直接用 Chrome / Edge 打开本目录的 `index.html`。无需安装、构建、外部字体或网络连接。

该目录独立运行，不依赖透明画布编辑器的 `app.js`、`style.css`、Wails 或桌面构建过程。

## 素材

包含 26 组控件，按全部状态展开为 40 张 PNG：

| 类别 | 内容 |
| --- | --- |
| 背景 | 科技主背景、纯净渐变、工程网格 |
| 按钮 | 主操作、次级操作、停止按钮的未激活 / 激活状态；禁用按钮；导航标签两态 |
| 指示灯 | 红、黄、绿、蓝、灰，每种均有点亮 / 熄灭两态 |
| 信息与数值 | 切角框、标题框、数值框、输入框、报警条、运行状态标签 |
| 其他 | 开关两态、水平进度、储罐液位、压力仪表、阀门与水泵两态、分区标题线 |

## 编辑与导出

1. 选择目标屏幕分辨率：800×480、1024×600、1280×800、1280×720 或 1920×1080。
2. 点击控件，调整尺寸、文字、状态、数值、光晕及透明背景。
3. 单独导出 PNG / SVG，或点击「导出整套素材」生成 ZIP。倍率可选 1× / 2× / 3×。
4. 对于工程内文字或动态变量，关闭「包含文字」后导出底图。

整套导出会包含所有控件及全部状态；背景使用目标屏幕分辨率，控件保留各自尺寸设置。ZIP 含分类目录、中文使用说明及 `manifest.json`（记录文件名、状态、像素尺寸、透明度和文字选项）。

编辑设置自动保存在当前浏览器的本地存储中。清除浏览器数据或换用浏览器可能移除设置；已导出的 PNG / SVG / ZIP 不受影响。「下载 HTML」下载完整离线程序源码。

## 整屏演示

「整屏预览」展示一套供液设备界面。支持启动 / 停止、自动 / 手动切换、运行参数编辑、模拟报警和报警复位。数据与操作只在浏览器中模拟；整屏可导出 PNG。

## 在 MCGS 工程中使用

- 将 PNG 导入工程图片资源，作为背景、状态图或装饰底图。
- 用 `normal / active`、`off / on` 等配对图片表现不同状态，在工程内关联实际变量和触摸动作。
- 数值、液位、仪表和进度的 PNG 是静态示例；持续变化的显示使用工程内的变量与绘图控件。
- 优先使用 1× 实际像素。透明 PNG 的支持情况需在具体触摸屏型号和工程版本上验证；如果透明显示异常，可关闭透明背景后重导出。
- HTML 生成的是画面素材，不是 MCGS 运行工程或 PLC 控制程序。
