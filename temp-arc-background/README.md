# 弧线背景临时工具

直接双击本目录的 `index.html`，在 Chrome / Edge 中离线使用，无需安装或构建。

默认画布为 **1600 × 960**：深蓝渐变背景、顶部蓝色区域、一条 1.2 px 的浅弧线。弧线在正中央达到纯白，离开峰值立即逐渐变暗，两侧为黑色；不添加白色长条、星芒或额外光晕。

## 调整

- **两端高度、中央下弯、线宽**：控制弧线几何形状，单位是画布原始像素。
- **亮点位置**：默认 50%，也可移动到任意位置。
- **渐变半径**：从亮点到恢复为两端颜色的单侧距离；默认 300 px。
- **衰减强度**：数值越大，亮白越集中。
- **颜色**：支持 `#RRGGBB`、`#RRGGBBAA`、`rgb(...)`、`rgba(...)` 等浏览器支持的明确色值。
- **预览缩放**：适应窗口、50%、100%、200%、400%；不改变导出尺寸。

线条渐变在单独的 SVG 描边上计算，背景独立绘制。亮度函数为 `max(0, 1 - sqrt(distance / radius)) ^ falloff`，只有距离为 0 的位置达到中央颜色，不设置白色平台区。左右对称，超过半径后为两端颜色。

## 导出

1. 选择 **完整背景**：导出背景、顶部区域和弧线。
2. 选择 **仅弧线 · 透明**：只导出弧线，保留整张画布的尺寸和坐标，方便原位叠加。预览中的棋盘格不会导出。
3. 点击 **导出 PNG** 或 **导出 SVG**，均按画布原尺寸导出，文件不包含工具界面。

参数会自动保存在当前浏览器；也可通过「保存参数 / 载入参数」保存 JSON。移动本 HTML、更换浏览器或清除浏览器数据前，建议保存参数文件。

本目录是独立的临时素材工具，不依赖项目根目录的编辑器代码，也不加入桌面程序的构建流程。
